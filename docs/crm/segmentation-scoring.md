# 06｜客户标签、分层与评分

## 为什么需要标签、分层和评分？

在 CRM 里，客户越多，越不能只靠列表管理。

如果一个销售每天面对 300 个客户，管理者面对几千个客户，系统必须回答三个问题：

1. 这个客户是谁？
2. 这个客户值不值得投入？
3. 这个客户下一步应该怎么运营？

标签、分层和评分就是为了解决这三个问题。

```text
标签：描述客户特征
分层：决定经营策略
评分：决定优先级
```

## 标签是什么？

标签是对客户特征的结构化描述。

例如：

- DTC 品牌
- 众筹项目
- 高订单量
- 需要海外仓
- 需要定制包装
- 重点国家
- API 对接需求
- 价格敏感
- 高复购潜力
- 售后问题多

标签的价值是让 CRM 能快速识别客户特征。

## 标签不能乱建

很多 CRM 最后会变成标签垃圾场。

例如：

```text
重要客户
很重要客户
超级重要客户
大客户
重点客户
重点跟进客户
```

这些标签重复、模糊、不可分析。

产品经理要设计标签体系，而不是放任用户随便打标签。

## 标签体系怎么设计？

推荐按照业务维度分组。

| 标签组 | 示例标签 | 用途 |
| --- | --- | --- |
| 客户类型 | 众筹品牌、DTC、跨境卖家、创新企业 | 判断客户画像 |
| 地域市场 | 北美、欧洲、日本、澳洲 | 判断服务网络与销售归属 |
| 业务需求 | 仓储、订单履约、国际物流、退货 | 判断服务匹配 |
| 订单规模 | 小批量、中批量、大批量 | 判断商业价值 |
| 意向强度 | 高意向、中意向、低意向 | 判断跟进优先级 |
| 风险状态 | 长期未跟进、报价后沉默、履约异常 | 触发预警 |
| 技术需求 | API 对接、Shopify 对接、平台对接 | 判断实施复杂度 |
| 客户价值 | 高 LTV、潜力客户、低价值客户 | 决定经营策略 |

## 客户分层是什么？

客户分层是把客户分成不同经营层级。

常见方式：

```text
A 类客户：高价值、高意向、高匹配
B 类客户：中等价值或潜力客户
C 类客户：低价值或待培育客户
D 类客户：无效或暂不匹配客户
```

但分层不能只按主观感觉，要有规则。

例如：

- 订单量
- 服务匹配度
- 预算能力
- 近期发货计划
- 国家覆盖匹配
- 历史成交记录
- 复购潜力
- 服务成本

## 评分是什么？

评分是一个更加细颗粒度的优先级判断。

标签描述特征，分层决定策略，评分决定顺序。

例如：

```text
客户 A：92 分，今天必须跟进
客户 B：76 分，本周重点跟进
客户 C：55 分，进入培育
客户 D：20 分，不进入销售队列
```

## ChinaDivision 的客户评分模型

可以设计成五大类：

### 1. 画像匹配度

- 是否为目标客户类型
- 是否来自重点国家
- 是否是品牌方或卖家
- 公司是否真实可信

### 2. 业务价值

- 月订单量
- SKU 数量
- 是否需要长期仓储
- 是否有多国家发货
- 是否有增值服务需求

### 3. 意向强度

- 是否提交询盘
- 是否查询报价
- 是否完成认证
- 是否主动预约沟通
- 是否多次访问关键页面

### 4. 服务匹配度

- 需求是否在公司服务范围内
- 发货目的地是否覆盖
- 是否需要特殊品类处理
- 是否有复杂合规要求

### 5. 风险与成本

- 客户价格敏感度
- 售后复杂度
- 实施复杂度
- 客户信用风险
- 需求不确定性

## 评分与动作必须绑定

评分最大的错误，是只展示一个分数，没有对应动作。

正确做法：

| 分数 | 客户层级 | 系统动作 |
| --- | --- | --- |
| 90-100 | S 级 | 自动分配资深销售，2 小时内响应，主管关注 |
| 75-89 | A 级 | 分配销售，24 小时内首次跟进 |
| 60-74 | B 级 | 普通销售跟进，进入培育计划 |
| 40-59 | C 级 | 自动邮件培育，补充资料后再判断 |
| 0-39 | D 级 | 低优先级或无效线索池 |

## 面试中怎么回答“如何设计客户标签和分层？”

推荐回答：

> 我会先明确标签和分层的目的。标签是为了描述客户特征，分层是为了制定不同经营策略，评分是为了确定销售优先级。针对 ChinaDivision，我会从客户类型、国家地区、服务需求、订单规模、意向强度、技术需求、风险状态和客户价值几个维度建立标签体系。分层上可以结合订单量、服务匹配度、近期发货计划、复购潜力和服务成本，把客户划分为 S/A/B/C 等层级。关键是标签、分层和评分不能只是展示字段，而要驱动后续动作，比如销售分配、跟进频率、自动营销、客户成功策略和风险预警。

## 面试官可能追问

### 追问 1：标签是人工打还是自动打？

推荐回答：

> 两种都需要。基础画像类标签可以通过表单、注册和认证信息自动生成；行为类标签可以根据访问、询价、下载、下单等行为自动生成；销售判断类标签可以人工补充；AI 可以辅助识别客户意图和风险。关键是要区分标签来源，并允许审核和修正。

### 追问 2：如何避免标签越来越乱？

推荐回答：

> 需要建立标签治理机制。第一，标签要分组管理，避免所有标签混在一起；第二，核心标签由管理员维护，普通用户不能随意创建；第三，定期清理重复、低使用率、含义模糊的标签；第四，标签命名要有规范；第五，重要标签要绑定业务动作和报表，否则就没有存在价值。

### 追问 3：客户评分和客户分层有什么区别？

推荐回答：

> 评分更细，用于排序和优先级判断；分层更稳定，用于制定经营策略。比如两个客户都属于 A 类客户，但一个 92 分，一个 78 分，销售今天应该优先跟进 92 分的客户。分层偏战略，评分偏动作。

### 追问 4：如果高分客户最后没成交，是否说明评分失败？

推荐回答：

> 不一定。评分衡量的是当时的转化潜力，不等于保证成交。需要看高分客户整体的 SQL 转化率、商机创建率、赢单率是否高于低分客户。如果整体有效，就说明模型有价值。对于未成交的高分客户，要分析失败原因，可能是报价、时效、服务范围、竞争对手或销售跟进问题，而不一定是评分本身错误。

## 本章小结

标签、分层和评分不是三个孤立功能。

它们共同服务于一个目标：

> 让企业用更低成本识别高价值客户，并为不同客户匹配不同销售和服务策略。
