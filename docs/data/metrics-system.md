# 10｜数据指标体系

## 指标不是为了汇报，而是为了定位问题

JD 中提到：

- Lead Conversion Rate
- MQL 转化率
- SQL 转化率
- 客户获客成本 CAC
- 客户生命周期价值 LTV
- 销售效率指标

很多人会背定义，但面试时更重要的是讲清楚：

> 为什么要看这个指标，看完以后要做什么决策。

指标的价值不是展示数字，而是定位增长链路上的问题。

## 一条完整的增长漏斗

可以从访问到复购拆成：

```text
官网访问量
  ↓
询盘提交数
  ↓
有效 Lead 数
  ↓
MQL 数
  ↓
SQL 数
  ↓
商机数
  ↓
报价数
  ↓
成交客户数
  ↓
履约订单数
  ↓
复购客户数
```

每一层都可以计算转化率。

## Lead Conversion Rate

Lead Conversion Rate 可以有多种口径，面试时要先明确定义。

常见口径：

- 访问 → 询盘
- Lead → MQL
- Lead → SQL
- Lead → 成交

如果不定义清楚，讨论会混乱。

### 面试回答建议

> 我会先和业务方统一 Lead Conversion Rate 的口径。对于增长团队，可能关注访问到询盘；对于销售团队，可能关注 Lead 到 SQL；对于管理层，可能更关注 Lead 到成交。不同口径代表不同问题，不能混在一起看。

## MQL 转化率

MQL 转化率通常看：

```text
MQL 数 / 有效 Lead 数
```

它回答的问题是：

> 市场获取来的线索中，有多少达到销售承接标准？

如果 MQL 转化率低，可能说明：

- 获客渠道质量差
- 官网表单太宽泛
- 客户画像不匹配
- 认证信息不足
- 评分规则过严

## SQL 转化率

SQL 转化率通常看：

```text
SQL 数 / MQL 数
```

它回答的问题是：

> 市场认为合格的线索，销售是否也认可？

如果 MQL 高但 SQL 低，说明市场和销售标准不一致。

可能问题：

- MQL 标准太宽
- 销售承接不及时
- 客户需求不真实
- 线索信息不完整
- 评分模型不准

## CAC：客户获客成本

CAC = 获取一个客户所花的平均成本。

简单公式：

```text
CAC = 销售和市场成本 / 新增客户数
```

但实际业务中要注意口径：

- 是否只算市场费用？
- 是否算销售人力成本？
- 是否按渠道拆分？
- 是否按客户类型拆分？
- 是否按成交客户还是有效客户计算？

对于 ChinaDivision，建议按客户类型和渠道拆 CAC。

例如：

| 渠道 | CAC | 客户质量 | 结论 |
| --- | --- | --- | --- |
| SEO | 低 | 中高 | 值得长期投入 |
| 广告 | 高 | 不稳定 | 需要优化投放 |
| 展会 | 高 | 高 | 适合大客户获取 |
| 老客户推荐 | 低 | 高 | 应设计推荐机制 |

## LTV：客户生命周期价值

LTV 是客户在整个生命周期内贡献的价值。

对于履约服务企业，LTV 不只是首单金额。

应该关注：

- 月订单量
- 仓储周期
- 物流频次
- 增值服务购买
- 复购周期
- 服务年限
- 毛利率
- 服务成本

简单理解：

```text
LTV = 客户平均周期收入 × 毛利率 × 留存周期
```

如果 LTV 高于 CAC 很多，说明获客是划算的。

如果 CAC 高但 LTV 也高，仍然可能值得投入。

## 销售效率指标

CRM 不只是看成交，还要看销售过程。

常见销售效率指标：

| 指标 | 说明 |
| --- | --- |
| 首响时长 | Lead 进入后多久首次联系 |
| 跟进及时率 | 是否按计划完成跟进 |
| 逾期跟进数 | 长期未跟进客户数量 |
| 人均跟进客户数 | 销售工作负载 |
| 人均商机数 | 销售机会承接能力 |
| 商机阶段停留时长 | 判断商机是否卡住 |
| 赢单率 | 商机最终成交比例 |
| 平均成交周期 | 从 Lead 到成交耗时 |
| 人均成交额 | 销售产出 |

## Portal 指标

User Portal 上线后，不能只看注册用户数。

更重要的是：

- 客户登录频次
- 自助查询率
- 订单查询成功率
- 工单自助提交率
- 人工咨询量下降比例
- 客户响应时长下降
- 客户满意度
- 复购率

## AI 指标

AI 功能也要有指标。

| AI 功能 | 指标 |
| --- | --- |
| AI 线索评分 | 高分线索 SQL 转化率、销售采纳率 |
| AI 客户摘要 | 销售查看率、摘要采纳率、信息查找时间下降 |
| AI 商机诊断 | 风险命中率、商机推进效率 |
| AI 工单分类 | 分类准确率、人工修正率、处理时长下降 |
| AI 邮件生成 | 采纳率、编辑率、发送率 |

## 指标体系怎么搭建？

建议按四层搭建。

### 第一层：增长指标

关注线索获取和转化。

- 访问量
- 询盘数
- Lead 数
- MQL 转化率
- SQL 转化率
- 成交率

### 第二层：销售指标

关注销售效率和过程质量。

- 首响时长
- 跟进及时率
- 商机赢单率
- 成交周期
- 人均产出

### 第三层：履约与服务指标

关注客户交付体验。

- 订单履约时效
- 物流异常率
- 工单处理时长
- SLA 达成率
- 客户满意度

### 第四层：经营指标

关注长期价值。

- CAC
- LTV
- 留存率
- 复购率
- 客户毛利
- 客户健康度

## 面试中怎么回答“如何建立数据指标体系？”

推荐回答：

> 我会按照客户生命周期建立指标体系，而不是孤立看单个指标。第一层是获客转化，关注访问、询盘、Lead、MQL、SQL、商机和成交；第二层是销售效率，关注首响时长、跟进及时率、商机阶段停留、赢单率和成交周期；第三层是履约服务，关注订单时效、物流异常、工单 SLA 和客户满意度；第四层是经营结果，关注 CAC、LTV、留存率和复购率。这样可以从增长入口一直看到客户长期价值，并且每个指标都能反向定位产品或业务问题。

## 面试官可能追问

### 追问 1：如果 Lead 很多但成交少，你怎么分析？

推荐回答：

> 我会先拆漏斗，看掉点发生在哪一层。如果访问到询盘低，可能是官网转化问题；如果 Lead 到 MQL 低，可能是渠道质量问题；如果 MQL 到 SQL 低，可能是评分和销售标准问题；如果 SQL 到商机低，可能是客户需求不明确或销售承接问题；如果商机到成交低，可能是报价、方案、时效或信任问题。不能直接说销售能力差，要通过漏斗定位。

### 追问 2：CAC 高一定不好吗？

推荐回答：

> 不一定，要结合 LTV 看。如果 CAC 高但客户 LTV 更高，长期仍然划算。比如大客户获客成本高，但订单量大、复购周期长、毛利高，就值得投入。关键是按渠道、客户类型和生命周期看 CAC/LTV，而不是看平均值。

### 追问 3：指标很多，第一阶段重点看什么？

推荐回答：

> 第一阶段我会优先看能直接定位增长瓶颈的核心指标，比如询盘数、有效 Lead 率、MQL 转化率、SQL 转化率、首响时长、商机创建率和赢单率。Portal 和 AI 上线后，再补充自助查询率、人工咨询下降率、AI 建议采纳率等效率指标。指标体系也要分阶段建设，不能一开始追求大而全。

## 本章小结

数据指标的核心价值是定位问题和驱动决策。

对于 ChinaDivision，指标体系要覆盖：

```text
获客 → 转化 → 销售 → 履约 → 服务 → 留存 → 复购
```

这样才能真正支撑数字化增长。
