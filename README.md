# CRM PM Handbook

《ChinaDivision 产品经理面试手册》是一套面向 CRM、B2B SaaS、用户增长、全球履约与供应链数字化方向的产品经理面试与成长教材。

本项目使用 VitePress 构建，目标不是堆砌面试题，而是把一场 ChinaDivision 产品经理面试拆成可学习、可复盘、可迁移的知识体系。

## 本地运行

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
npm run docs:preview
```

## 内容定位

- 业务理解：全球订单履约、仓储、国际物流、供应链服务
- 产品体系：CRM、用户增长、User Portal、客户成功、营销自动化
- AI 能力：线索评分、客户分层、销售分配、智能客服、AI 管理摘要
- 数据指标：Lead Conversion Rate、MQL、SQL、CAC、LTV、销售效率
- 面试表达：标准答案、追问拆解、错误回答、项目映射

## 写作原则

1. 先讲为什么，再讲是什么。
2. 先讲业务链路，再讲产品模块。
3. 先建立理解，再辅助记忆。
4. 每个知识点都尽量落到面试回答。
5. 每个面试回答都尽量能映射到候选人项目经历。
